# Village-level Voting Pattern Similarity Analysis 

## 前言

「章魚里」（又稱選情章魚哥）是指在台灣各項選舉中，其開票結果與最終全區或全國結果高度相似的村里，常用來作為開票時的趨勢觀察指標。

### 研究問題

1. 人口結構會變動、選舉有不同類型，將一個特定村鄰里訂為長年不變的章魚里是否具有其合理性?
2. 章魚里其開票結果與最終結果高度相似的定義，似乎很模糊。是否有可能透過數據分析結果，來觀察各村里選舉結果與最終結果的相似度如何?


## 材料與方法

### 資料來源

這個專案透過中選會選舉及公投資料庫 [2024 ー 第16任總統副總統選舉](https://db.cec.gov.tw/ElecTable/Election/ElecTickets?dataType=tickets&typeId=ELC&subjectId=P0&legisId=00&themeId=4d83db17c1707e3defae5dc4d4e9c800&dataLevel=N&prvCode=00&cityCode=000&areaCode=00&deptCode=000&liCode=0000) 資料，計算全台灣 7700 餘個村鄰里的得票率，並將其與全國得票率相比較，針對兩個報章媒體的不合理論點提出反思。

### 工具/程式

- 使用`Pandas`與`Sqlite`建立資料庫
- `NumPy`計算各村鄰里之餘弦相似度
- 再用`Gradio`製作成品
- 最後部署至Hugging Face Space上

    **可藉由輸入縣市名稱(county)、鄉鎮市區名稱(town)及村鄰里名稱(village)，查詢各村鄰里之排名及其餘弦相似度。**

    [去Hugging Face 看看成果](https://huggingface.co/spaces/druidtracy/taiwan_presidential_election_2024)


### 分析方法

透過分別計算三組候選人在7700餘個村鄰里的得票率，與最終得票率之 **餘弦相似度(Consine Similarity)** ，來觀察與最終得票率相似的村鄰里有哪些。



## 研究結果

將7738個村鄰里得票率與最終得票率之餘弦相似度，由高至低排序後，發現與最終得票率相似度最高的村鄰里不一定是長年被認定的村鄰里。

- 相似度最高前三名村鄰里:

    南投縣草屯鎮中山里 (99.999998%)<br>
    新北市土城區樂利里 (99.999997%)<br>
    南投縣草屯鎮新豐里 (99.999993%)

- 常見章魚里的排名:

    臺北市士林區天玉里 排名2482 相似度 99.241715%<br>
    新北市鶯歌區建德里 排名979 相似度 99.750225%


## 結論

- 本專案以 2024 年總統副總統選舉的村里層級得票資料為基礎，透過餘弦相似度量化各村里的候選人得票率分布與全國得票率分布之間的相似程度，並據此建立排名。分析結果顯示，相似度最高的村里不一定是過去媒體經常提及的指標性章魚里，例如臺北市士林區天玉里排名第 2,482 名，而新北市鶯歌區建德里排名第 979 名。這表示在本次選舉與本專案採用的衡量方法下，傳統上被視為選情指標的村里，並非必然與全國得票率最為相似。

- 本次分析也顯示，「章魚里」的判定可以從經驗性的描述轉化為可量化的比較問題。然而，餘弦相似度衡量的是候選人得票率分布的相似程度，並不直接代表預測選舉結果的準確率；單次選舉的分析結果，也不足以判斷某個村里是否能長期反映全國選情。因此，章魚里的代表性仍須結合不同年度、不同類型的選舉資料進一步驗證。

- 透過本專案，將原始選舉資料經由 `Pandas` 與 `SQLite` 整理，再使用 `NumPy` 計算**餘弦相似度**，最後以 `Gradio` 建立查詢介面並部署至 Hugging Face Spaces，完成**從資料處理、分析到應用部署的實作流程**。這個專案不僅將模糊的「選情相似」概念轉化為可比較的數值，也呈現了資料分析方法在公共議題探索與資訊視覺化應用上的可能性。



## 如何重現
- 安裝 [Miniconda](https://docs.anaconda.com/miniconda)
- 依據 environment.yml 建立環境：

```bash
conda env create -f environment.yml
```

- 將 data/ 資料夾中的「總統-A05-4-候選人得票數一覽表-各投開票所」22 個試算表檔案放到專案資料夾的 data/ 資料夾中
- 啟動環境並執行 python create_taiwan_presidential_election_2024_db.py 就能在 data/ 資料夾中建立 taiwan_presidential_election_2024.db
- 啟動環境並執行 python app.py 並前往 http://127.0.0.1:7860 瀏覽成品。
